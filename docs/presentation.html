1. Problem Tanımı ve Mühendislik Yaklaşımı

Yazılım Geliştirme Yaşam Döngüsünde (SDLC) Statik Analizin Yeri

❌ Geleneksel Yöntemlerin Sınırları

  • Derleme Bağımlılığı: Klasik analiz araçları projenin hatasız derlenmesini gerektirir; eksik bağımlılıklarda çalışmaz.
  • Gözden Kaçan Zafiyetler: Bellek sızıntıları (`UNCLOSED_RESOURCE`) ve gömülü şifreler manuel code review süreçlerinde kolayca gözden kaçar.
  • Eylemsiz Raporlama: Mevcut araçlar sorunu gösterir fakat geliştiriciye yapıcı veya otomatize edilmiş bir çözüm sunmaz.

✅ J-Inspector Çözüm Mimarisi

  • Compile-Free AST Parsing: JavaParser altyapısı ile kod derlenmeden sözdizimsel düğümler (Nodes) seviyesinde anında tarama.
  • AI Refactoring Motoru: Bulunan her ihlal tipi için context-aware (bağlama duyarlı) otomatik çözüm kodları basma.
  • Shift-Left Security: Hataları ve güvenlik açıklarını canlıya çıkmadan, henüz commit/PR aşamasında engelleme.

2. Sistem Mimarisi ve Teknoloji Yığını

Modüler, Genişletilebilir ve Katmanlı Yazılım Mimarısı

🧩 1. Core AST Engine

  • JavaParser 3.x Integration: `.java` dosyalarını Abstract Syntax Tree'ye çevirir.
  • Visitor Design Pattern: `VoidVisitorAdapter` kullanarak kod düğümlerini (Class, Method, Try-Catch) milisaniyeler içinde gezebilir.

🤖 2. AI & Rule Layer

  • Analyzer Engines: Her kural için izole edilmiş dinamik analiz sınıfları.
  • AI Suggestion Generator: İhlal tespit edildiğinde Clean Code prensiplerine uygun çözüm üreten katman.

📊 3. Export & CI/CD Pipeline

  • Multi-Format Exporter: Interaktif **HTML Dashboard** ve makinece okunabilir **JSON** raporları.
  • GitHub Actions: Automated build, self-inspection ve artifact dağıtım hattı.

3. Detaylı Analiz Kuralları Matrisi

Güvenlik, Performans ve Mimari Kod Taramaları

CRITICAL UNCLOSED_RESOURCE

Kapatılmayan `InputStream`, `FileReader` ve DB bağlantılarını tespit eder. Bellek sızıntılarını ve `OutOfMemoryError` riskini önler.

CRITICAL HARDCODED_CREDENTIALS

Kod içerisine gömülmüş API Key, JWT Token ve DB şifrelerini regex tabanlı aramayla tespit eder. Bilgi sızıntısını engeller.

HIGH EMPTY_CATCH_BLOCK

Hataların sessizce yutulduğu boş `catch` bloklarını raporlayarak uygulamanın kilitlenmesini ve belirsiz davranışlarını engeller.

MEDIUM CYCLOMATIC_COMPLEXITY

Aşırı `if-else` ve döngü içeren yüksek karmaşıklıktaki spagetti metotları bularak refactoring yapılması gerektiğini bildirir.

💻 CLI Çalıştırma Komutları

Proje terminal üzerinden parametrik olarak kolayca çalıştırılabilir:

mvn clean package -DskipTests

# 2. Statik analizi başlatın (Tüm formatlarda rapor üretir)
java -jar target/j-inspector-3.0-RELEASE-jar-with-dependencies.jar -p . -f all -o report
