2. Gelişmiş Analiz Kuralları

Güvenlik, Performans ve Clean Code Denetimleri

CRITICAL UNCLOSED_RESOURCE

Kapatılmayan akış ve veritabanı bağlantılarını bularak bellekteki kaynak sızıntılarını engeller.

CRITICAL HARDCODED_CREDENTIALS

Kod içerisine gömülmüş gizli şifre, API key ve token bilgilerini tespit eder.

HIGH EMPTY_CATCH_BLOCK

Sessizce yutulan exceptions bloklarını yakalar ve logging/rethrow önerileri sunar.

MEDIUM CYCLOMATIC_COMPLEXITY

Aşırı dallanmış metotları analiz ederek spagetti kod oluşumunu engeller.
