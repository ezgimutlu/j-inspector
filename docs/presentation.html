1. Problem ve Çözüm Yaklaşımı

Yazılım Kalitesinde Statik Kod Analizinin Rolü

❌ Mevcut Sorunlar

  • Derleme anında fark edilmeyen mantıksal ve teknik borçlar (Technical Debt).
  • Okunabilirliği düşük, karmaşık (High Cyclomatic Complexity) ve spagetti kodlar.
  • Boş catch blokları yüzünden sessizce yutulan kritik sistem hataları.
  • Kod içine hardcode yazılmış sihirli sayılar (Magic Numbers).

✅ J-Inspector Çözümü

  • AST Analizi: Kodu metin olarak değil, Soyut Sözdizim Ağacı (AST) olarak inceler.
  • Milisaniyelik Performans: Multithreaded mimari ile anında analiz.
  • Görsel Raporlama: Anlaşılır Dark-Mode HTML Dashboard ve JSON çıktıları.
  • CLI Entegrasyonu: CI/CD süreçlerine kolayca bağlanabilir yapıda.

2. Sistem Mimarisi & Teknoloji Yığını

Modüler ve Genişletilebilir Katman Tasarımı

⚙️ Core Engine

Java 17+ dil standartlarında yazılmış, nesne yönelimli ve katmanlı mimari.


Paketler: analyzer, model, parser, util

🌳 AST Parsing

JavaParser Framework kullanılarak kodlar semantik düğümlere (AST Nodes) dönüştürülür.


Deseni: Visitor Pattern (VoidVisitorAdapter)

💻 CLI & Reporting

Picocli entegrasyonu ile terminal komutları yönetilir. Jackson & Custom Exporter ile HTML/JSON raporlanır.

3. Analiz Kuralları ve Şiddet Seviyeleri

J-Inspector Tarafından Otomatik Denetlenen İhlaller

CRITICAL EMPTY_CATCH_BLOCK

Hataların sessizce yutulduğu boş catch bloklarını tespit eder. Güvenlik ve debug süreçleri için kritiktir.

HIGH LONG_METHOD

Belirlenen eşik değerden (Örn: 30 satır) daha uzun metotları yakalayarak refactoring önerir.

MEDIUM CYCLOMATIC_COMPLEXITY

İç içe geçmiş if/else, döngüler ve dallanmaları ölçerek karmaşıklık skoru sunar.

LOW MAGIC_NUMBER

Kod içerisinde sabitleştirilmeden (constant) doğrudan kullanılan açıklamasız sayıları bulur.

4. Komut Satırı (CLI) Kullanımı

Fat-JAR ve Esnek Parametre Desteği

🚀 Derleme ve Çalıştırma Komutu

Maven ile paketlenen tek bir JAR dosyası üzerinden çalışır:

java -jar target/j-inspector-3.0-RELEASE.jar -p . -f all -o jinspector_report

-p / --path

Taranacak Java projesinin dizin yolunu belirtir.

-f / --format

Çıktı formatını belirler: html, json veya all.

-o / --output

Rapor dosyasının oluşturulacağı hedef adı ayarlar.

6. Tamamlanan Modüller & Self-Inspection Testi

Üretim Standardında Tamamlanmış Yazılım Yetenekleri
